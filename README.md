# Intro_to_AIML_Practical

This repository contains Prolog programs developed as part of the Introduction to Artificial Intelligence and Machine Learning practical course.

## Experiments

- **Experiment 1:** Knowledge Base using Facts, Predicates, Clauses, and Goals
- **Experiment 2:** Arithmetic Operations, Factorial, and Fibonacci
- **Experiment 3:** List Manipulation: Append, Reverse, Member Search, and List Length
- **Experiment 4:** College Timetable Knowledge Base: Faculty, Subjects, and Classrooms
- **Experiment 5:** Student Performance Analysis: Topper, Average, and Fail Classification
- **Experiment 6:** Breadth-First Search (BFS) for Shortest Path in a Graph
- **Experiment 7:** Greedy Best-First Search using a Heuristic Function
- **Experiment 8:** A* Search Algorithm for Optimal Path Finding
- **Experiment 9:** Hill Climbing Algorithm for Optimization
- **Experiment 10:** Simulated Annealing for Optimization
- **Experiment 11:** Map Coloring using Constraint Satisfaction and Backtracking
- **Experiment 12:** N-Queens Problem


## Software Requirements

- SWI-Prolog
- A text editor or IDE

## How to Run

1. Install SWI-Prolog.
2. Open the required `.pl` file in SWI-Prolog.
3. Load the program.
4. Execute the relevant query at the Prolog prompt.

## Learning Objectives

- Understand facts, predicates, rules, and queries.
- Perform list operations and recursive computations.
- Represent knowledge using a Prolog database.
- Implement search algorithms and graph traversal.
- Apply heuristic search, optimization, and backtracking.
