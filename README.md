# Intro_to_AIML_Practical

This repository contains practical programs completed as part of the Introduction to Artificial Intelligence and Machine Learning lab.

## Experiments

- **Experiment 1:** Knowledge Base using Facts, Predicates, Clauses, and Goals
- **Experiment 2:** Arithmetic Operations, Factorial, and Fibonacci
- **Experiment 12:** N-Queens Problem

## Software Requirements

- SWI-Prolog
- Any text editor or IDE

## How to Run

1. Download or clone this repository.
2. Open the required `.pl` file in SWI-Prolog.
3. Load the program and run the appropriate query.
